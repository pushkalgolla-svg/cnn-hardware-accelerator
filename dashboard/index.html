  • ASIC Gate-Level Synthesis & PPA Analysis: Executed standard cell synthesis using Yosys 0.70 and ABC, mapping RTL designs to generic CMOS logic gates to quantify logic gate complexity vs. throughput trade-offs (2,474 vs 28,522 generic cells; not physical silicon area) and separating buffer preload cycles from active computation.
